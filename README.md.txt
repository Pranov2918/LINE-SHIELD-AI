# LINE-SHIELD AI Project

This is an AI-driven software solution for detecting and isolating LT line faults in real time.

## Technologies Used
* **Backend:** Python, FastAPI, TensorFlow/Keras, MQTT
* **Frontend:** React, Bootstrap, Leaflet.js, WebSockets
* **Data Simulation:** MATLAB/Simulink

## How to Run
1.  **Start the Backend:** Run `uvicorn main_final:app` in the main folder.
2.  **Start the Frontend:** Run `npm start` in the `/frontend` folder.
3.  **Start the Simulator:** Run `python stream_simulator.py` in the main folder.
